### 2. 원문 내부 불일치 (인용 시 반드시 병기)

- **SPRFMO SC13-Doc20**: 요약문은 2024년 조업일을 "114,745 days"로, Table 2는 "**114,475**"로 적었다. 2023년 어획도 Table 1은 "494,000", Table 2는 "**494,500**"으로 다르다. **표(Table) 값을 채택**했다.
- **아르헨티나 2026년 시즌 해석 충돌**: INIDEP은 4월 6일까지 누적 어획이 **2000년 이래 최고**라고 기술한다. 반면 선행 아카이브는 "**04-22 자원 급감으로 전면 조기 종료**"라고 적었다. 두 진술은 양립 가능하다 — 누적은 사상 최고인 동시에 **4월 CPUE가 13.2 → 2.5 t/일로 붕괴**(1-20)했기 때문이다. **"기록적 풍어"와 "조기 폐쇄"를 서로 반박 근거로 쓰지 말 것.**
- **아르헨티나 상반기 하역량**: INIDEP 공식 147,152 t(4월 6일까지, 지거선) vs Undercurrent 188,400 t(상반기). **집계 범위·기간·선종이 달라 직접 비교 불가.**

### 3. 종 합산 위험

- **1-27~1-30 한국 통계의 "오징어"는 살오징어 단일종이 아닐 가능성이 높다.** 어업생산동향조사는 통상 "오징어류"로 집계한다. 위젯에 쓸 때 **"살오징어"로 라벨링하지 말 것.**
- **1-29 원양 "오징어류" 73,600 t은 명시적 합산치다.** 포클랜드 Loligo + 페루 pota + 기타가 섞여 있다.
- 축1의 포클랜드·아르헨티나·페루·칠레 수치는 각각 **다른 종**이다. 세계 합계를 만들려면 FAO FishStat(로컬 보유)을 쓰고 이 표의 국가별 값을 더하지 말 것.

### 4. 쿼터 ≠ 어획량, 권고 ≠ 채택

- **페루 589,230 t은 LMCTP(한도)이지 어획량이 아니다.** 실제 하역은 429,778.10 t(1-22).
- **IMARPE 권고(MSY 평균 539,230 t)와 PRODUCE 채택치(589,230 t)는 다르다** (2-15). 채택치가 권고 평균을 **9.3% 상회**한다. 이 격차 자체가 위젯 소재다. **권고를 한도로 적는 실수를 하지 말 것.**
- **칠레 200,000 t은 쿼터이고, 2025년 실제 하역은 약 95,000 t**(추정, 그래프 판독) — **소진율 약 48%**. 쿼터 미소진이 자원 부족 때문인지 시장·가공능력 때문인지는 **당사자 간 쟁점이며 확정 사실이 아니다**(4-05 참조).
- **SPRFMO CMM 18-2026에는 TAC가 없다.** 척수·GT 상한만 있다. "SPRFMO 오징어 쿼터"라는 표현을 쓰면 안 된다.
- **버퍼존 조치는 채택되지 않았다**(2-11). 페루 제안서(COMM14-Prop16)를 발효 중인 조치로 인용하면 오류다.

### 5. 신선도 경고

- **3-08(EU 자급률 13%)과 4-02(1인당 오징어 5.402 kg)는 각각 2017년·2014년 기준**이다. 3년 신선도 기준 미달로 **"역사적 맥락"으로만** 사용하고, 위젯 본문 수치로 쓰지 말 것.
- **1-01~1-06의 중국 데이터는 2024년이 최신**이다. SC14(2026-09) 이후 2025년 데이터가 나온다.
