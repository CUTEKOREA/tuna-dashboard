## 1. 실측 결과 — 무엇이 분리 가능한가

신라교역 색깔은 **차트나 데이터에 있지 않고, SIT/TAK(전략 제언) 텍스트에만** 묻어 있습니다.

```
[차트·데이터 레이어]  공공 API (KCS·Comtrade·KAMIS·FAOSTAT·USDA·WITS·OEC)  →  ✅ 재사용 가능
[전략 제언 레이어]    SIT/TAK 텍스트 — 신라교역 맞춤                        →  🔄 교체 필요
```

**즉, 차트를 다시 만들 필요가 없습니다.** 텍스트만 갈면 됩니다. 이게 이 계획의 실현 가능성을 결정합니다.

## 2. 살균(Sanitize) 체크리스트

판매용 빌드를 만들 때 반드시 통과해야 하는 검증입니다.

```bash
# 1) 식별자 스캔 — 0건이어야 함
grep -rniE "신라교역|신라에스지|Silla|SEIN |BAO LUCKY|MOAKONA|MOAMARI|TAIHO|S/SPR|S/PIO|S/CHA|S/EXP|N/STAR|PAPA RESTY" <판매빌드경로>/

# 2) 거래처·전략문건 스캔 — 0건이어야 함
grep -rniE "FCF CO|SG '26|운영방안|당사|자사" <판매빌드경로>/
#    ※ FCF 단독은 Free Cash Flow(재무용어)일 수 있으므로 문맥 확인

# 3) 기밀 컴포넌트 잔존 스캔 — 0건이어야 함
grep -rlE "Fleet|Unloading|Vds|Vessel|Carrier" <판매빌드경로>/components/

# 4) 1인칭 표현 스캔 — SIT/TAK가 일반화됐는지
grep -rn "당사\|자사\|우리\s*회사" <판매빌드경로>/components/
```

**추가 필수 조치**

- [ ] `HANDOFF.md`, `CONTEXT.md`, `PROJECT.md`, `ORIGINAL_REQUEST.md` **제외** (신라교역 업무 이력이 전부 들어 있음)
- [ ] `data/`, `public/data/` 내 신라교역 실적 JSON **제외**
- [ ] git 히스토리 **분리** — 새 저장소로 파일만 복사 (기존 히스토리에 기밀 커밋 메시지 다수)
- [ ] 로고(`logo.png`, `logo1.png`) **교체**
- [ ] Supabase 프로젝트 **분리** (신라교역 DB 접근 키 제거)
- [ ] API 키 **재발급** (신라교역 계정 키를 판매 상품에 쓰면 안 됨)

> **git 히스토리 분리는 타협 불가입니다.** 커밋 메시지에 `"7/30 송클라 통조림 공장 및 하역 현황"`, `"수역별 회사별 조업일수 소진현황"` 같은 문구가 그대로 남아 있습니다.

## 4. 7일 내 현실성 — 정직한 평가

| 항목 | 평가 |
|---|---|
| 기술적 분리 가능성 | ✅ **확인됨** (14종 클린, 아키텍처가 이미 품목 단위로 분리) |
| 살균 작업 소요 | 🟡 파일럿 1종 기준 **1~2일** |
| 판로 확보 | 🔴 **없음. 이게 병목입니다.** |
| **7일 내 판매 성사** | 🔴 **낮음** |
| **8~9월 수익화** | 🟢 **높음** |

**냉정한 결론:** 만들어놨다고 팔리지 않습니다. B2B SaaS는 판로가 전부이고, 판로 구축에는 최소 3~6주가 걸립니다.

### 그럼에도 지금 가치가 있는 이유 3가지

1. **C트랙(신규 영업)의 전환율을 극적으로 높입니다.**
   "만들어드릴 수 있습니다" (제안) → **"이미 만들어져 있습니다. 지금 보시겠습니까?"** (증명)
   완성품 데모가 있는 것과 없는 것은 콜드 영업에서 완전히 다른 게임입니다.

2. **A트랙이 거절당했을 때의 대안입니다.**
   신라교역이 "안 쓰겠다"고 해도 7개월이 매몰비용이 되지 않습니다.

3. **반복 수익 구조입니다.**
   신라교역 1곳에서 월 100만 원 vs. 품목 라이선스 월 30만 원 × N개사.
   후자가 장기적으로 훨씬 큽니다.

### 7일 안에 이 트랙에서 할 수 있는 것

- [ ] **파일럿 1종만 살균**해서 데모 링크 확보 (고등어 권장 — 988줄로 가장 완성도 높고 데이터 소스 7종)
- [ ] 그 데모 링크를 **B트랙·C트랙 영업에 즉시 투입**
- [ ] 14종 전체 상품화는 **8월 중순 목표**로 잡기

> 7일 안에 14종을 다 상품화하려 하면 **아무것도 못 팝니다.** 1종을 완성해서 영업 무기로 쓰세요.

## 6. 마지막 확인 사항

이 트랙을 진행하기 전에 스스로 답해야 할 질문입니다.

1. **신라교역과 이 대시보드에 대해 구두 합의라도 있었습니까?**
   "이건 회사 것" 같은 대화가 오갔다면 스핀오프 전에 반드시 정리해야 합니다.

2. **어종별 대시보드의 기획 방향을 신라교역이 지시했습니까?**
   단순 요청 수준이면 문제없지만, 상세 기획을 제공받았다면 공동저작물 소지가 있습니다.

3. **회사 계정의 API 키·NotebookLM·Google Drive 자료를 썼습니까?**
   썼다면 해당 데이터는 판매 상품에서 **반드시 제거**해야 합니다.

> 세 질문 중 하나라도 걸리는 게 있으면, **A트랙 계약서에 제6조 2항을 넣어 명문화**하는 것이
> 가장 안전하고 저렴한 해결책입니다. 100만 원을 받으면서 동시에 스핀오프 권리를 확보하는 셈입니다.
