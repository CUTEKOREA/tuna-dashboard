## 🟢 B트랙 실행법 — 지인·인맥 소액 용역 (작지만 빠름)

> **7일 내 실입금 확률이 가장 높은 경로입니다. A트랙보다 우선순위를 낮게 보지 마세요.**

### 왜 이게 더 빠른가

| | 법인 (A트랙) | 개인·소상공인 (B트랙) |
|---|---|---|
| 결재선 | 3~5단계 | **없음 (본인이 결정)** |
| 정산 주기 | 익월 지급 | **당일 계좌이체** |
| 금액 | 100만 원 | 20~50만 원 |
| 소요 기간 | 1~3주 | **1~3일** |

**20만 원 × 5건 = 100만 원.** 법인 1건보다 이쪽이 7일 안에 도달할 가능성이 높습니다.

### 무엇을 팔 수 있는가

당신의 실력(Next.js 16 · React 19 · Supabase · Recharts · 공공 API 연동)으로 소상공인·개인 대상 즉시 판매 가능한 것:

| 상품 | 소요 | 단가 | 비고 |
|---|---|---|---|
| 소상공인 매출 대시보드 | 2~3일 | 30~80만 원 | 엑셀 → 웹 대시보드 전환 |
| 엑셀 자동화 / 데이터 정리 | 반나절~1일 | 10~30만 원 | 이미 Python 17,000줄 보유 |
| 랜딩페이지 제작 | 1~2일 | 30~50만 원 | Next.js 즉시 가능 |
| 공공데이터 API 연동 | 1~2일 | 30~60만 원 | 75개 엔드포인트 연동 경험 |
| 기존 사이트 오류 수정·개선 | 몇 시간 | 10~20만 원 | 빠른 현금화 |

### 발송 메시지 (복붙용)

```
안녕하세요 OO님, 오랜만에 연락드립니다.

제가 요즘 데이터 대시보드랑 웹 개발 쪽 일을 하고 있는데,
8월에 일정이 조금 비어서 단기 프로젝트를 몇 건 받으려고 합니다.

혹시 주변에 이런 거 필요하신 분 계시면 소개 부탁드려도 될까요.

 · 엑셀로 관리하시는 데이터를 웹 대시보드로 전환
 · 공공데이터/API 연동 자동화
 · 랜딩페이지·소개 페이지 제작
 · 기존 사이트 오류 수정

작은 건도 괜찮고, 빠르게 작업해드릴 수 있습니다.
포트폴리오 필요하시면 바로 보내드리겠습니다.
```

> **⚠️ 여기서도 "급하다"는 말은 하지 마세요.** "일정이 비어서"가 정확하고 자연스러운 표현입니다.
> 급하다고 하면 단가가 깎이고, 소개도 줄어듭니다.
