# 글로벌 무역 인텔리전스 대시보드
## 운영·유지보수 계약 전환 제안서

**제출일:** 2026년 8월 1일
**제출처:** 신라교역 주식회사
**문서 구분:** 운영 계약 제안 (Proposal for Operations & Maintenance Agreement)

---

## Executive Summary

현재 신라교역의 해양수산본부 일일 업무보고, 운반선 하역 현황, 수역별 조업일수(VDS) 소진 관리, 선단 운영 현황이 본 대시보드 시스템을 통해 매일 처리되고 있습니다.

본 시스템은 2026년 1월부터 7개월간 **무상으로 구축·운영**되어 왔습니다. 누적 산출물은 코드 148,000줄, 화면 컴포넌트 433개, 외부 데이터 연동 150개 규모이며, 소프트웨어 노임단가 기준 환산 가치는 **약 4,900만 원**입니다.

본 제안서는 **기 제공분에 대한 소급 청구를 포함하지 않습니다.** 다만 시스템이 실무 운영에 편입된 현 시점에서, 안정적인 지속 운영을 보장하기 위한 **정식 운영 계약으로의 전환**을 제안드립니다.

> **제안 핵심:** 월 100만 원 (VAT 별도) 기본 운영 계약
> 구축 가치 4,900만 원 대비 월 2% 수준이며, 현재 무상으로 제공 중인 운영 업무를 계약 범위 내로 정상화하는 것을 목적으로 합니다.

## 1. 현재 운영 중인 시스템 현황

### 1-1. 실무 편입 상태

본 시스템은 시범 단계가 아니라 **일일 업무 프로세스에 편입된 운영 시스템**입니다.

| 업무 영역 | 대시보드 | 갱신 주기 | 근거 데이터 |
|---|---|---|---|
| 해양수산본부 일일 업무보고 | 선단 운영 (`/fleet`) | 일간 | 일일 업무보고 원표 |
| 운반선 하역 현황 | 하역 현황 (`/unloading`) | 일간 | 하역 일보, 어창별 검품 기록 |
| 수역별 조업일수 관리 | VDS 전략 매트릭스 | 주간 | 수역별·선사별 조업일수 소진 현황 |
| 통조림 공장·하역 물류 | 물류·가공 (`/logistics`) | 주간 | 송클라 공장 가동 현황 |
| 글로벌 시황 | 시장 동향 (`/market`) | 주간 | Atuna, NotebookLM 원문 분석 |

**최근 반영 이력 (2026년 7월):**
- 7/31 — 260731 수역별 조업일수 현황(VDS) 분석 반영
- 7/31 — 송클라 통조림 공장 및 하역 현황 데이터 반영
- 7/30 — 일일 업무보고 260731(조업일 7/30) 반영, 5개 파일 갱신
- 7/28 — 선단 운영 일일/주간 탭 분리 개편

### 1-2. 시스템 규모

| 구분 | 수량 |
|---|---|
| Commodity 인텔리전스 대시보드 | **35종** |

| 외부 데이터 연동 API | **150개 파일 / 75개 엔드포인트 그룹** |
| 총 코드 규모 | **약 148,000줄** |
| 기술 문서 | **367건** |

**대시보드 구성 (35종):**

- **실시간 운영 (4)** — 시장 동향, 선단 운영, 물류·가공, 하역 현황
- **어종별 인텔리전스 (12)** — 참치, 고등어, 갈치, 오징어, 주꾸미, 낙지, 명태, 가자미, 새우, 연어, 골뱅이, 김
- **농산물 (6)** — 캐슈넛, 카사바, 마늘, 당근, 코코아, 망고스틴
- **축산물 (3)** — 닭, 돼지고기, 소고기
- **전략 분석 (10)** — 통합 인텔리전스, 글로벌 OEM(태국 44개사·베트남 294개사 M&A 후보), 선대 전략, 국내 위판장, 냉동창고, MSC 전략, 사시미/스테이크 전략, 선망선 DB, 연구 재료, 중고차

## 2. 무상 제공 구조의 지속 가능성 문제

### 2-1. 현 구조

지난 7개월간 다음 업무가 무상으로 수행되었습니다.

- 일일 업무보고 데이터 반영 (조업 실적, 선박 위치, 적재량, 운반선 하역)
- 주간 보고서 기반 지표 갱신 (선장 실적, 수역별 쿼터)
- 외부 API 장애 대응 및 데이터 정합성 검증
- 신규 위젯·대시보드 기획 및 개발
- 인프라 운영 (Vercel 배포, Supabase DB, 빌드 검증)

### 2-2. 리스크

무상 구조에서는 다음이 **보장되지 않습니다.**

| 리스크 | 내용 |
|---|---|
| 대응 시간 미보장 | 데이터 오류·장애 발생 시 복구 시점을 약정할 수 없음 |
| 갱신 연속성 미보장 | 일일 보고 반영이 지연되면 의사결정 데이터가 과거값으로 고정됨 |
| 인수인계 부재 | 운영 주체 변경 시 문서·권한 이관 절차가 정의되어 있지 않음 |
| 데이터 정합성 책임 소재 불명 | 잘못된 수치로 인한 의사결정 리스크의 책임 범위가 미정의 |

일일 업무보고와 VDS 쿼터 관리가 이미 본 시스템에 의존하고 있는 만큼, 위 항목은 **운영 리스크**에 해당합니다. 정식 계약은 이 리스크를 해소하기 위한 절차입니다.

## 3. 제안 — 운영 계약 3안

### A안. 기본 운영 (Essential) — **권장**

> **월 100만 원** (VAT 별도)

현재 무상으로 수행 중인 운영 업무를 계약 범위로 정상화하는 최소 구성입니다.

| 항목 | 범위 |
|---|---|
| 일일 업무보고 반영 | 영업일 기준 **1영업일 내** 대시보드 반영 |
| 주간 보고서 반영 | 주 1회 정기 갱신 |
| 장애 대응 | 영업일 기준 **1영업일 내** 1차 대응 |
| 데이터 정합성 검증 | 갱신 시 타입체크·빌드·회귀 테스트 수행 |
| 인프라 운영 | Vercel 배포, DB 운영, 외부 API 키 관리 |
| 경미한 수정 | 월 4건 이내 (라벨·수치·색상·레이아웃 조정) |

### B안. 표준 운영 (Standard)

> **월 250만 원** (VAT 별도)

| 추가 항목 | 범위 |
|---|---|
| 신규 위젯 개발 | 월 **2종** (기획 → 데이터 연동 → SIT/TAK 작성 포함) |
| 장애 대응 | **당일** 1차 대응 |
| 월간 리포트 | 시황 요약 및 대시보드 인사이트 정리 (월 1회) |
| 데이터 소스 확장 | 신규 외부 API 연동 월 1건 |

### C안. 전략 파트너 (Strategic)

> **월 450만 원** (VAT 별도)

B안 전체 + 다음을 포함합니다.

| 추가 항목 | 범위 |
|---|---|
| 신규 Commodity 대시보드 | **분기 1종** 신규 구축 |
| 임원 브리핑 | 월 1회 대면/화상 인사이트 브리핑 |

## 5. 제안 범위에서 제외한 사항

투명성을 위해 명시합니다.

1. **기 구축분(4,900만 원 상당)에 대한 소급 청구를 하지 않습니다.**
   2026년 1월~7월 개발·운영분은 무상 제공으로 종결합니다.

2. **기 구축 산출물의 사용 권한을 제한하지 않습니다.**
   현재 운영 중인 시스템은 계약 체결 여부와 무관하게 계속 사용하실 수 있습니다.

3. **본 제안은 서비스 중단을 조건으로 하지 않습니다.**
   계약 미체결 시에도 기존 시스템은 그대로 유지되며, 다만 신규 갱신·장애 대응은 무보장 상태가 됩니다.
