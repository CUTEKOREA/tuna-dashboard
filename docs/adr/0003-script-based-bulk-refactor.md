# 5개 이상 위젯에 동일 패턴이 적용되는 변경은 일회용 스크립트로 일괄 처리한다

영문→한글, 단위 표기 추가, 색상 토큰 교체 등 동일 패턴이 5개 위젯 이상에 걸치는 변경은 IDE 수작업을 금하고 `scripts/fix_<주제>.py` 또는 `.js` 일괄 변환기로 처리한다(L-07). 운영 중 16개 누적 사례에서 수작업 변환이 매번 7~15% 누락·불일치를 남긴 반면 스크립트 + diff 리뷰는 0% 누락을 달성했기 때문이다. Trade-off: 루트 디렉터리에 일회용 스크립트가 누적되지만, 한 번 머지된 후엔 `_archive/scripts/`로 옮겨 영구 보관한다.
