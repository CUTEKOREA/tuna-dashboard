## 0. 한 줄 결론

참치왕국은 지금 **"편집된 정적 리포트"**다 — 위젯·해석(SIT/TAK)이 코드에 고정되고 사용자는 읽는다.
Metabase의 본질은 색이 아니라 **"모든 픽셀이 다음 질문의 입구"**라는 문법이다 (클릭 → 필터·원천·입도 하강).
이번 개편은 ① Metabase 디자인 언어로 **리스킨**하고 ② 그 밑에 **상호작용 층**을 깔되
③ 참치왕국의 역격차 자산(SIT/TAK 내러티브·TelemetryBadge 정직 표기·위젯당 출처 의무)은 **보존**한다.

## 1. 레퍼런스 분석 요약 (실측)

### 1-1. Metabase 디자인 언어
- **색**: 브랜드 블루 `#509EE3`가 사이트·제품·차트 1번색까지 관통. 텍스트는 순검정이 아니라
  잉크 네이비 `#22242b`(헤딩) + 회청 `#5a6072`(본문). 배경 흰색~`#f9fafb`, 보더 `#e2e4e9`.
  마케팅 사이트는 라이트 온리, **제품은 라이트+다크 둘 다** (다크 베이스 orion ≈ `#0C1C27`).
- **차트 팔레트 8색** (오픈소스 repo 원문): `#509EE3` `#88BF4D` `#A989C5` `#EF8C8C` `#F9D45C`
  `#F2A86F` `#98D9D9` `#7172AD` + tint/shade ±12.5%. **시리즈 이름 해시로 색을 고정 배정**
  (같은 지표 = 어느 화면에서든 같은 색). 제품 UI 시맨틱: 필터=퍼플, 요약=그린.
- **타이포**: Lato **400/700/900 3단**(500·600 안 씀), 대형 타이틀에 강한 네거티브 트래킹(-2~-4%),
  코드·수치 Roboto Mono. 제품 헤딩 스케일 32/24/20/17/14.
- **카드**: 흰 배경 + 1px 보더 + radius 8~16px + 극저채도 그림자(#101828 기반) — **구분의 주역은
  그림자가 아니라 보더·여백**. 필터 위젯은 흰 pill(아이콘+라벨+체브론).
- **대시보드 관례**: 제목 아래 텍스트 탭(활성=블루 언더라인) → 필터 바 한 줄 → 텍스트 카드가
  섹션 헤딩 역할 → KPI 카드는 초대형 숫자 + ▲▼ 증감 2줄.

### 1-2. 기능 이식성 판정 (질의 엔진 없는 참치왕국 기준)
| 판정 | 기능 |
| --- | --- |
| 원형 이식 (1) | Treemap 차트 |
| 축소 번안 (9) | Drill-through(교차필터·클릭 동작·zoom) · Data Studio(지표 SSOT·리니지·파손 진단) · 구독+PDF 발송 · Trend/Goal/조건부 서식 · Usage analytics(Vercel Analytics) · CSV 파이프라인 표준화 · Models/Collections(메타데이터·검증 배지) · Dashboard invites · AI 요약(SIT/TAK 파이프라인) |
| 불가 (5) | Query builder · SQL editor · Embedded analytics(해당 없음) · Data segregation(불요) · Explorations(상세 미공개) |

### 1-3. 현행 격차 (grep 실측)
- 상호작용 층 전무: drill 0건, 전역 필터·기간 선택 0건, cross-filter 0건.
- 색·폰트 **정의부는 2~4파일로 수렴** (globals.css `--dsc-*`/`--w-*` 16쌍 + cosmo.css) —
  리스킨은 싸다. 비싼 건 hex 하드코딩 잔존 **341/419 tsx** (L-07 대상)와 스냅샷 갱신.
- 선결 정리 대상 (V2.5 스펙과 모순 상태): Google Fonts CDN `@import` 잔재, Spotify 인젝션
  블록(전역 `!important`), 3층 누적 레거시 토큰, `--chart-s1~8` 보급 미완(사용처 1파일).

## 3. 디자인 시스템 전환

### 3-1. 색 — 결정 분기 (사용자 결정 필요)

**A안 — Metabase Light 전환 (추천)**
- 배경 `#f9fafb` / 카드 `#ffffff` + 1px `#e2e4e9` / 헤딩 `#22242b` / 본문 `#5a6072`.
- 브랜드 액센트: Metabase 블루 원형 대신 **참치왕국 시그니처 유지** — 페이지 액센트는 기존
  commodity 그라디언트의 대표색 1색을 라이트 배경용 톤으로 재조정 (D-04 매핑 보존).
- 추천 이유: 사용자가 라이트 레퍼런스를 지정하고 "색상 변경"을 명시했다. Metabase 문법(보더
  중심 구분, 저채도 그림자, 잉크 네이비)은 라이트에서 완성된다. C레벨 인쇄·주간 PDF 발송(§4-6)
  과도 라이트가 맞다.
- 비용·리스크: hex 잔존 341파일이 다크 전제(밝은 글자색 하드코딩) — 토큰화 표면만 먼저 바뀌고
  L-07 3차로 완성(§5). 선박 야간 사진 히어로·데이터 발광 문법은 다크 전제 → 해당 페이지(fleet·
  unloading)는 **다크 아일랜드로 존치**하거나 라이트용 재생성 필요 (결정 사항 ③).
- Metabase 제품처럼 **다크 토글 병행** 가능 — 기존 다크 토큰을 `data-theme="dark"`로 강등 보존.

**B안 — 다크 유지 + Metabase 다크 리톤**
- 현행 zinc(`#0a0a0b`)를 Metabase 다크 베이스 orion 잉크 네이비(`#0C1C27` 계열)로 리톤,
  8색 차트 팔레트·문법만 이식. 기존 자산(사진·발광) 충돌 없음. "색상 변경" 폭은 작다.

### 3-2. 차트 팔레트 (A/B 공통)
- `--chart-s1~s8`을 Metabase accent 8색으로 교체 + **시리즈명 해시 고정 배정** 유틸 도입
  (`lib/chart-standards.ts`에 `colorForSeries(name)`) — 같은 지표는 전 화면 동일 색.
- 5+ 시리즈 dash 병행 의무(기존 Grok 반증 게이트)는 유지. 기존 `--w-*` 브리지는 그대로 두고
  값만 재조정 (345파일 자동 반영).

### 3-3. 타이포
- 한글엔 Lato가 없다 → **Pretendard 400/700/900 3단** (next/font self-host, CDN 금지 유지)
  + 수치·코드 **Roboto Mono** (IBM Plex Mono에서 교체 — Metabase 원형).
- 대형 타이틀 네거티브 트래킹 -2% 채택. 제품 헤딩 스케일(32/24/20/17/14)로 `--dsc-*` 타이포
  토큰 재조정. 웨이트 500·600 사용 금지 (3단 규율).

### 3-4. 카드·레이아웃 문법
- 카드 계약 유지(radius 12 / 1px 보더 / 좌측 3px 액센트) — Metabase 문법과 이미 동형.
  그림자만 `#101828` 기반 극저채도 2레이어로 교체.
- 필터 위젯 = pill (아이콘+라벨+체브론, 1px 보더 radius 8) — §4-1 전역 필터 바의 시각 표준.
- 텍스트 탭: PillTabs를 "활성=액센트 언더라인" 변형으로 확장 (기존 pill형과 병존, 페이지 선택).
- KPI 카드: 초대형 숫자 + **▲▼ 증감 2줄** (§4-2 Trend 카드와 한 몸).

## 4. 표현방법 고도화 (기능 로드맵)

### P1 — 상호작용의 뼈대 (이번 개편의 본체)
1. **전역 필터 바 + 기간 선택 + Time grouping** — 페이지 상단 한 줄. 기간(프리셋+커스텀)·
   commodity 축 필터(해역·거래처·선박 등 페이지별 1-2축)·시간 입도(주/월/분기/년) 일괄 전환.
   주입 지점은 `lib/data/` 인테이크 단일 — 위젯은 필터된 데이터를 받을 뿐. **URL searchParams
   동기화**로 필터 상태 공유 링크 확보 (Metabase permalink 번안).
2. **Trend 카드** — KPI에 전기 대비 증감(▲녹/▼적 % + 비교값) 자동 계산. HeroZone KPI부터.
3. **Goal line + 조건부 서식 + 셀 미니바** — 차트 목표선(ReferenceLine 표준화), 테이블 색
   레인지·셀 내 가로 미니바(CSS만으로 구현). TAK가 말로 하던 "상한 주시"를 선으로 기계화.

### P2 — 클릭 문법 (drill 축소판)
4. **Cross-filter**: 차트 항목 클릭 → 같은 페이지 다른 위젯 필터 갱신 (전역 필터 주입 재사용).
   **범례 클릭 시리즈 토글**, **기간 드래그 zoom**(Recharts Brush). 클릭 → **원천 레코드 시트**
   (해당 상세가 JSON에 있는 위젯부터 — 예: 하역 주차 클릭 → 그 주 항차 목록 모달).
5. **SIT/TAK 변수 문법**: Metabase 텍스트 카드 `{{변수}}`·`[[조건부]]`의 번안 — SIT 문장 안
   숫자를 필터 반응 토큰으로 치환. **정합성 정책 결정 필요**(결정 사항 ②): 필터 변경 시
   ⓐ SIT/TAK을 변수로 동적화 vs ⓑ "전체 기간 기준" 라벨을 달고 고정.
6. **신규 차트형**: Treemap(원형 — 품목 구성비), Waterfall(마진 브리지), Gauge/Progress(목표
   대비). 차트-데이터 적합성 가이드(부적합 차트 강등)는 dataviz 스킬 규범으로 대체.

### P3 — 운영 고도화
7. **구독 + PDF**: cron + Puppeteer로 주간 스냅샷 PDF 생성 → 이메일/Slack 발송 (Metabase
   구독 번안). 방콕 주간보고·데일리 브리핑 파이프라인과 자연 결합.
8. **Data Studio 축소판**: 지표 정의 SSOT 모듈(예: cifPerKg 계산 1곳), 리니지 스크립트
   (위젯→lib/data→JSON 의존 그래프 = Closure 자동화), 파손 진단 테스트(JSON 필드 변경 시
   영향 위젯 검출) — 기존 architecture-guards의 연장.
9. **Usage 피드백**: Vercel Web Analytics로 "안 읽히는 위젯" 식별 → widget-audit 우선순위 입력.
10. **검증 배지**: 4-Axis 감사 통과 위젯에 체크마크 (TelemetryBadge 확장, Collections 번안).

### 도입하지 않는 것 (명시적 제외)
Query builder·SQL editor·런타임 자연어 질의·X-ray 자동 대시보드·행/열 권한·멀티테넌트 —
질의 엔진 전제이거나 큐레이션 철학과 충돌. "새 질문 = 위젯 코드 + W-04 체크리스트" 모델 유지.

## 5. 구현 전략 (단계·게이트)

0. **선결 정리** (모순 소거, 1커밋): CDN `@import` 제거 → next/font 완결, Spotify 인젝션 블록
   제거, 미사용 레거시 토큰 정리. 이거 없이 리스킨하면 `!important`가 새 팔레트를 뚫는다.
1. **토큰 리스킨** (정의부 2~4파일): `--dsc-*` 값 전환 + `--w-*` 16쌍 재조정 + `--chart-s1~8`
   교체 + cosmo/panofi 브리지 확인. 파일럿 페이지 1곳(결정 사항 ③)으로 실화면 판정.
2. **표면 컴포넌트**: HeroZone·PillTabs(언더라인 변형)·WidgetCard·필터 바 신설·Trend KPI.
3. **P1 기능** (§4-1~3) → 파일럿 페이지에 전역 필터 실장.
4. **L-07 3차**: hex 잔존 341파일 일괄 치환 (`scripts/fix_widget_colors.py` 확장 — 기존
   phase 1·2 인프라 재사용). 스냅샷은 단계별 분할 커밋 (일괄 갱신 금지 — V2.5 규율 승계).
5. **P2·P3**: 별도 스펙으로 분할 (본 기획서는 방향과 우선순위까지만 확정).

각 단계 게이트: `npm run verify` + 실화면 스크린샷 판정 + 반증 리뷰(작성자≠검증자).

## 6. 리스크 (정직 표기)

- **정합성**: 전역 필터 도입 시 정적 SIT/TAK 숫자가 필터된 화면과 어긋난다 — 결정 사항 ②를
  설계 단계에서 못 박아야 한다. 미결정 상태로 필터만 깔면 L-09(정직 표기)를 문장 층에서 위반.
- **다크 자산 충돌 (A안)**: 선박 야간 사진·데이터 발광·War Room 무드는 라이트와 충돌.
  fleet/unloading 다크 아일랜드 존치 시 "통일감" 요구와 긴장 — 파일럿 판정으로 결정.
- **클라이언트 세션 잠금**: BI화(공유 링크·구독 발송)가 진행되면 sessionStorage 게이트로는
  부족 — P3 시점에 진짜 인증(Supabase Auth 등) 재논의.
- **스냅샷 대량 갱신**: 색 전환은 픽셀이 실제 변한다 — 단계 분할·전후 스크린샷 판정으로 통제.
