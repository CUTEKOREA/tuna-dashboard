## 0. Executive Summary (TL;DR)

참치왕국 대시보드는 **35개 commodity 대시보드 · 422개 위젯 · 144개 API 라우트 · 73,936 LOC**로 성장한 대형 자산이다. 기능 폭은 이미 시장 최상급이나, **품질·신뢰·확장성의 하부구조가 성장 속도를 못 따라왔다.** 측정된 3대 구조 부채:

1. **품질 안전망 부재** — 테스트 **0개**, lint **비활성**(`echo 'Skipping lint'`), `@ts-nocheck` **31파일**. 회귀는 배포 후 사용자가 발견.
2. **복붙 아키텍처** — 위젯 **107개가 JSON을 직접 import**(과거 패치 스크립트 200+개의 원인), 대시보드 35개가 5-Pillar 골격을 각자 복제. 이번 세션만 해도 "루트 배경 15개 개별 수정", "토큰 하나가 24파일에 하드코딩"이 반복 확인됨.
3. **신뢰 표기 수동 관리** — isLive 라우트 103개인데 위젯의 LIVE/STATIC 라벨 정합성은 사람이 감사(룰북 L-09). 자동 게이트 없음.

**핵심 제안:** 기능을 더 얹기 전에 **"플랫폼화"** — 공통 팩토리·데이터 인테이크 레이어·자동 신뢰 게이트·CI 안전망을 깔아, 35→50 commodity로 갈 때 한계비용이 줄도록 전환한다. 그 위에 **교차-commodity 인텔리전스**(단일 품목 대시보드들의 합 이상)라는 제품 도약을 얹는다.

## 2. 개선 전략 — 6개 축

### 축 A. 품질 안전망 (Foundation) 🔴 최우선

문제: 테스트 0 · lint off · @ts-nocheck 31. 배포 후 사용자가 버그 발견(이번 세션 "주꾸미 검정 배경"도 사용자 제보로 발견).

- **A-1** `package.json` lint 복구 → `next lint` + `tsc --noEmit`를 pre-push 게이트(L-03)에 편입.
- **A-2** `@ts-nocheck` 31파일 점진 제거 — 신규/수정 파일부터 금지, codemod로 명시 타입 주입.
- **A-3** **데이터 계약 테스트** 도입: 144개 라우트의 응답 스키마(zod)를 정의하고, 라우트당 1개 계약 테스트(`isLive` boolean, 단위 톤/천USD, dest 합≈100%). Vitest 도입, CI에서 실행.
- **A-4** 위젯 스냅샷 테스트: 대표 위젯 20개 렌더 스냅샷으로 디자인 회귀 차단.

**측정 목표:** 라우트 계약 커버리지 0→100%, 타입 오류 억제 파일 31→0.

### 축 B. 데이터 인테이크 레이어 (Decoupling) 🔴

문제: 107개 위젯이 `../data/*.json` 직접 import → 데이터 형식 변경 시 파일 수백 개 패치(과거 200+ fix 스크립트).

- **B-1** `lib/data/` 단일 인테이크 모듈: `getCommodityData(commodity, metric)` 한 진입점. 위젯은 JSON 경로를 몰라야 함.
- **B-2** HS 코드 단일 출처 `app/api/_shared/hs-codes.ts`(L-04) — 이번 세션 김 1212.21.1x/2008.99.50.10 발견처럼, 코드가 라우트에 흩어짐. 매핑 테이블 1곳 집중.
- **B-3** 데이터 버전·출처 메타를 데이터에 동봉(source, fetchedAt, method) → cardDesc 자동 생성.

**측정 목표:** 직접 import 107→0, 데이터 형식 변경 1건당 수정 파일 수백→1.

### 축 C. 대시보드 팩토리 (Scale) 🟡

문제: 35개 대시보드가 5-Pillar nav·KPI 그리드·배경·헤더를 각자 복제. 이번 세션 "루트 배경 15개 개별 수정"이 그 증거.

- **C-1** `<CommodityDashboard config={...}>` 팩토리 — pillar 구조·시그니처 그라디언트·KPI·위젯 배치를 **config 객체**로 선언. 신규 품목 = config 1개 작성.
- **C-2** 기존 35개를 config-driven으로 점진 이관(고위험 대시보드는 후순위).
- **C-3** 공통 셸(사이드바·AmbientBackground·배경 투명 규약)을 레이아웃으로 승격 → 배경 블로킹 버그 재발 방지.

**측정 목표:** 신규 commodity 추가 비용 "수백 줄 복붙"→"config 1개 + 데이터".

### 축 D. 교차-Commodity 인텔리전스 (Product Leap) 🟢 차별화

지금은 품목별 사일로. 진짜 가치는 **품목 간 연결**.

- **D-1** **대체재 탄력성 매트릭스** — 참치↔고등어↔연어↔닭↔돼지 가격·수요 교차. 룰북 P4(대체재 교차탄력성)를 전 품목 통합 뷰로.
- **D-2** **통합 리스크 레이더** — 환율·유가·기후(엘니뇨)·관세 충격이 35개 품목에 미치는 영향 히트맵 1장.
- **D-3** **포트폴리오 마진 대시보드** — C레벨용: 전 품목 수익성·조달 리스크를 한 화면. PEF 임원 페르소나(P-01)의 실제 의사결정 화면.
- **D-4** **이상 탐지·알림** — LIVE 라우트 103개에 임계치 걸어 급변(관세 발효·쿼터 소진·가격 스파이크) 시 알림.

### 축 E. 성능·관측성 (Ops) 🟡

- **E-1** 73,936 LOC 번들 — 대시보드별 코드 스플릿 점검, 미사용 recharts import 정리, 번들 예산(budget) CI 게이트.
- **E-2** 144 라우트 캐시 전략 표준화(revalidate·stale-while-revalidate), 외부 API 실패율·응답시간 관측(현재 apiHealth 필드 산발적).
- **E-3** `.bak_api` 6개 등 죽은 파일 제거, `_archive/` 정리.

### 축 F. 협업 규율 (2-Agent) 🟡

- **F-1** Fleet/Unloading [AG] WIP 장기 미커밋 → worktree 분리 규약 강제(AGENTS.md에 있으나 미준수). Aurora 미적용 잔여도 여기서 해소.
- **F-2** CI에 [CC]/[AG] 커밋 규약·HANDOFF 갱신 체크 자동화.
