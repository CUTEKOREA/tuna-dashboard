01 — 문제

엑셀은 과거를 기록하고,
대시보드는 다음 수를 보여줍니다

수입 단가는 관세청에, 경쟁국 물량은 UN Comtrade에, 산지 시세는 KAMIS에, 생산량은 FAOSTAT에 흩어져 있습니다. 담당자가 매달 이걸 손으로 모아 엑셀에 붙이는 동안 데이터는 이미 과거가 됩니다.

저는 이 소스들을 HSK 10자리 기준으로 직접 연동해, 단가·물량·관세·환율·운임이 한 화면에서 자동으로 갱신되는 구조를 만듭니다. 담당자가 데이터를 모으는 대신 판단에 시간을 쓰게 하는 것이 목표입니다.

모든 차트에는 산출 방법론과 출처를 한 줄로 명기하고, 데이터 신선도(실시간·동기화·정적)를 화면에 표시합니다. 출처를 못 대는 숫자는 넣지 않습니다.

02 — 구조

공급망 5단 프레임워크

품목이 무엇이든 원료에서 소비자까지의 경로는 같은 다섯 구간을 지납니다. 모든 대시보드를 이 구조로 배치해, 담당자가 다른 품목으로 옮겨가도 화면을 새로 배울 필요가 없게 만듭니다.

  1. Ⅰ원료 수급 생산량·어획량, 기후 리스크, 산지 단가 추이
  2. Ⅱ가공·생산 가동률, 수율, 인건비 및 원가 구조
  3. Ⅲ물류·통관 해상·항공 운임, 콜드체인, 검역·SPS 장벽
  4. Ⅳ판매·수요 점유율, 소매가 전가, 대체재 교차 탄력성
  5. Ⅴ지속가능성 탄소 발자국, 인증(MSC 등), 규제 대응

05 — 화면 단위

모든 차트가 갖추는 것

보기 좋은 차트가 아니라 결정을 내릴 수 있는 차트를 만듭니다. 모든 화면 단위는 예외 없이 아래 다섯 가지를 포함합니다.

산출 근거
차트 바로 아래 계산 방법과 출처를 한 줄로 명기. 숫자의 출처를 되묻지 않아도 됩니다.
신선도 표시
데이터가 실시간 연동인지, 정기 동기화인지, 고정값인지를 갱신 일자와 함께 화면에 노출. 오래된 숫자로 판단하는 사고를 막습니다.
현황 진단
차트가 지금 무엇을 말하고 있는지를 수치를 포함해 2~3문장으로 서술.
실행 제안
그래서 무엇을 해야 하는지를 마진·리스크 관점의 실행 지침으로 1~2문장. 관찰이 아니라 행동으로 끝냅니다.
단위·용어
모든 수치에 단위를 괄호로 표기(원/kg, $/MT, 톤). 축·범례·툴팁은 전부 한글. 업계 약어는 마우스를 올리면 풀어서 설명합니다.

07 — 진행 방식

의뢰 유형

품목 대시보드 구축 300만 원~ 귀사 취급 품목 1종. 기획·데이터 연동·화면 구축 포함. 통상 3주.
기존 화면 고도화 100만 원~ 운영 중인 시스템에 분석 모듈 추가. 통상 1주.
운영·유지보수 월 100만 원~ 정기 데이터 갱신, 장애 대응, 경미한 수정 포함.
시황 분석 리포트 150만 원~ 품목별 심층 분석 문서. 대시보드 없이 단건 의뢰 가능.

금액은 VAT 별도이며 범위에 따라 조정됩니다. 단건 의뢰는 착수금 50% 조건으로 진행합니다.

취급 품목을 알려주시면 해당 화면을 보여드리겠습니다.

이미 구축된 품목이면 바로 데모를 보실 수 있고, 없는 품목이면 기존 구조를 기준으로 구성안과 소요 기간을 회신드립니다. 검토용 자료 요청도 편하게 주십시오.
