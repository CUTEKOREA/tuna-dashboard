## 🟡 LIVE schema fine-tune 대상 (사용자 컨펌 (가))

### W6 KCS 한국 수입 파트너 — 응답 부족
- **현재**: `hsSgnGrpCol=HS4`, `hsSgn=0201` 4자리
- **문제**: KCS unipass는 보통 10자리 HSK 요구 (룰북 L-04)
- **수정 방향**: HSK 10자리 매핑 (`0201100000` `0201200000` `0201300000` + 0202 시리즈)
- **대안**: KCS unipass의 별도 endpoint(`getNewExpStaXmlnsService`) 시도

### W7 KOSIS 한국 수급 — schema 불일치
- **현재**: `orgId=114, tblId=DT_114_2017_S0034` (추정)
- **문제**: KOSIS 실제 통계표 ID 잘못된 매핑
- **수정 방향**: 정확한 통계표 ID 조사 필요 — 가축통계조사 (101_DT_1IZ1101) 또는 식량수급표 (KREI 별도)
- **대안**: KREI 식량수급표 API (별도 endpoint)

### W8 KAMIS 한우 가격 — 응답 부족
- **현재**: `p_kindcode=00` (전체)
- **문제**: 한우는 등급별(`01` 1++/`02` 1+/`03` 1) 필수
- **수정 방향**: `p_kindcode=01` (한우 1++) + 수입쇠고기는 별도 `p_itemcode=412 p_kindcode=02`
