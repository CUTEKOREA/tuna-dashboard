# 조종석 모드 (전문가 밀도 토글) — 설계

> 2026-08-17 [CC] · 근거: YC 디자인 영상 분석(테슬라 vs 비행기 조종석) + SOUL.md 밀도 철학.
> **설계만 확정 — 구현은 소유자 승인 후.** V3 스펙(2026-08-15-metabase-bi-redesign)의 후속.

## 문제

페이지마다 밀도가 표류한다 — market은 리포트 톤, 파노피는 터미널 밀도, 방콕은 그 중간.
같은 사람이 보는 화면인데 «얼마나 촘촘하게 보여줄 것인가»의 기준이 페이지 구현자마다 달랐다.

## 원칙 (SOUL.md 밀도 철학)

- **테슬라 모드(기본)**: 핵심 숫자 크게, 카드 여백 넉넉히, 컬러 액션 최소. 5초 판단용.
- **조종석 모드(옵트인)**: 파노피 `pf-*` 프리미티브 밀도 — stat strip·헤어라인 패널·12칸 격자.
  지표를 한 화면에 최대한. 스크롤 대신 밀도.

## 설계

1. **전역 토글 1개** — 사이드바 하단 «조종석 모드» 스위치. 상태는 `localStorage('cockpit-mode')`
   + 루트 `data-density="cockpit"` 속성. 페이지별 토글은 만들지 않는다 (모드 파편화 방지).
2. **CSS 계층으로 구현** — `[data-density='cockpit']`에서 토큰만 조정:
   카드 패딩 축소(24→14px)·카드 간격 축소·`--dsc-kpi-size` 한 단계 하향·타이포 스케일 -1단·
   그리드 2열→3열(≥1600px에서 4열). **컴포넌트 분기 금지** — 토큰이 못 미치는 곳만 최소 오버라이드.
3. **정보량 확장은 2단계** — 1단계는 같은 정보의 밀도 압축만. 숨겨진 지표를 조종석에서만
   노출하는 것(예: 위젯 보조 통계 행)은 페이지별 후속으로, 위젯 단위 `cockpitExtra` 슬롯 규약만
   지금 정의해 둔다.

   **2단계 구현됨 (2026-08-17).** `ChartSlot.cockpitExtra?: () => ReactNode` 슬롯과
   `components/market-understanding/CockpitExtra.tsx`(`CockpitOnly`·`SeriesStats`).
   노출은 CSS 한 곳(`.cockpit-only`)이 가른다 — JS 분기 없음, 하이드레이션 불일치 없음.

   - **새 사실을 만들지 않는다.** 보조 지표의 값은 전부 *그 차트가 받은 배열*에서 세거나
     고른 것이다(표본 수·최대·최소·합계·차트에서 잘린 개수). 다른 출처를 끌어오거나
     비율·증감률을 새로 계산하지 않는다 — 보조 지표는 아무도 검수하지 않기 때문이다.
   - `SeriesStats` 는 제네릭이라 **없는 키를 적으면 컴파일에서 걸린다.** 실제로 새우
     국가별의 값 칸이 「생산량」이 아니라 「합계」여서 이 장치가 필요했다.
   - `sum` 은 합계가 뜻을 갖는 계열에서만 켠다. 단가·비율 계열에 켜면 안 된다.
   - 적용: 새우·오징어·골뱅이·고등어 8개 차트. 참치는 figure 를 인라인으로 그려
     슬롯 규약이 없으므로 **미적용**(후속).
4. **적용 제외**: 파노피·코스모(이미 조종석 밀도), 메일. 히어로는 양 모드 동일(정체성 유지).
5. **테스트**: 토글 → data-density 속성 계약 + 대표 페이지 스냅샷 2종(모드별) + reduced-motion 무관.

   **이행됨 (2026-08-17).** `__tests__/cockpit-mode-contract.test.ts` 11건 ·
   `__tests__/cockpit-exclusions.test.ts` 6건.

   - 토글 구현을 `lib/cockpit-density.ts` 로 뺐다. 900줄짜리 페이지 안에 인라인이면
     테스트가 못 붙고, 키 문자열이 바뀌어도 아무도 모른다.
   - **스냅샷 대신 값을 박았다.** 스냅샷은 깨지면 갱신하게 되고, 그러면 되돌아가도 통과한다.
     조종석이 줄이는 일곱 토큰의 값을 그대로 단언한다.
   - **상수는 리터럴로 못 박는다.** 테스트가 상수를 import 해 비교하면 이름을 바꿔도
     따라가 통과한다 — 실제로 돌연변이 시험에서 저장 키를 바꿨는데 전부 통과했다.
     그 값이 바뀌면 이미 켜 둔 사람의 설정이 조용히 초기화된다.
   - 제외(§4)는 **성립 방식이 둘**이라 그 전제를 검사한다 — 파노피는 조종석 토큰을
     하나도 안 쓰고, 코스모는 `--dsc-card-radius` 하나만 써서 그것만 되돌린다.
     제외 규칙이 짧은 것은 빠뜨려서가 아니라 필요한 만큼만 짚었기 때문이다.
   - 네 종류 돌연변이(토큰 삭제·값 되돌림·키 개명·transition 삽입)와 제외 쪽 네 종류가
     전부 실패로 잡히는 것을 확인했다.
