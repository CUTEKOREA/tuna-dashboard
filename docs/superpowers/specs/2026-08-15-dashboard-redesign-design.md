## 1. 레퍼런스 해석 — 무엇을 가져오나

| 레퍼런스 | 가져오는 DNA | 버리는 것 |
| --- | --- | --- |
| **Twisty** | 에디토리얼 타이포 계층(초대형 헤드라인·KPI), 낮은 밀도, 둥근 카드(16-20px), 여백 호흡 | 라이트 팔레트, 세리프 서체, 코랄 액센트 |
| **Vexto** | 지도=캔버스(UI가 지도 위에 부유), 경고→권고 패널, 필 탭 내비, 라이브 수치 부유 카드 | 모바일 앱 레이어 |
| **Raktor** | 선박=히어로, 발광 하이라이트(화물칸=데이터), 하단 임무 카드 스트립, 선박 프로필 카드 | 무기·군사 모티프 |

셋의 공통 문법: **화면당 주인공 1개, 나머지는 부유하는 보조 카드, 탭으로 계층화.**

## 2. 디자인 시스템 V2 — 토큰 층

### 2.1 팔레트
- 배경: 현행 `gray-900` → 심해 틸-차콜 `#0A141D` 계열 반 단계 심화. 카드 글래스(`bg-white/5 backdrop-blur-md`) 유지, 보더 `rgba(255,255,255,0.05)` 유지
- **시그니처 그라디언트(D-04) 전부 생존.** 용법 확장: 카드 헤더 → 발광 액센트(히어로 하이라이트·KPI 글로우·활성 탭 배경)
- 경보 체계: 기존 rose/amber 유지. Vexto의 적색 틴트 경고 패널 문법 도입

### 2.2 타이포 계층 (이번 개편의 실질)
- 페이지 타이틀: 48-64px, 웨이트 200-300, 히어로 위에 직접 얹음 (Vexto "Traffic Management" 문법)
- KPI 숫자: 56-72px tabular-nums, 웨이트 700, 단위는 18-20px 병기 (`18,643` MT)
- 카드 제목·본문: 현행 유지. 폰트는 Pretendard 계열 유지 — 명조 헤드라인은 War Room 톤과 충돌해 기각
- 웨이트 대비(200 vs 700)로 에디토리얼 무드 구현

### 2.3 모션 언어 (framer-motion·react-countup 기설치)
- 카드 진입 스태거 60ms / KPI 카운트업 / LIVE 배지 펄스 / 호버 리프트 `translateY(-2px)`+글로우 / 히어로 발광 숨쉬기 3-4s
- `prefers-reduced-motion` 전부 존중 (기존 AnimatedNumber 패턴 답습)

## 3. 히어로 존 3유형 (재사용 컴포넌트 `HeroZone`)

| 유형 | 레퍼런스 | 적용 | 구성 |
| --- | --- | --- | --- |
| **A. Vessel Ops** | Raktor | `/fleet` `/unloading` | 선박 위성뷰 이미지 + 발광 오버레이(어획·하역량→화물칸 하이라이트) + 하단 선박 카드 스트립 + 좌측 선박 프로필 카드 |
| **B. Live Map** | Vexto | `/logistics` | Leaflet 다크 위성 타일, 방콕↔부산 항로·운반선 마커, 우측 경고→권고 패널, 하단 부유 지표 카드 |
| **C. Executive KPI** | Twisty | `/market` + commodity 전체 | 초대형 KPI 1 + 주간 변화 시각화 + 보조 KPI 3-4 |

- 경고 패널의 "권고" 줄 = **기존 위젯 TAK 텍스트 재사용.** 데이터 계약 변경 없음
- HeroZone은 이미지·지도·KPI를 슬롯으로 받는 단일 컴포넌트 — 이미지 교체(Grok↔SVG 폴백) 가능 구조

## 4. IA 재편 규칙

- 페이지 = 히어로 존 1 + 핵심 카드 4-6 + 나머지 **필 탭** 계층화
- 필 탭 = 기존 Universal 5-Pillar 그대로 (원료 수급/가공·생산/물류·통관/판매·수요/ESG)
- 위젯 내부 룰 전부 유지: SIT/TAK·TelemetryBadge·cardDesc·한글 100%·7자 truncate·W-04 체크리스트 무손상
- 신설 메뉴(코스모·방콕사무소)는 병행 트랙에서 현행 디자인으로 먼저 추가 → Phase 2에서 셸만 V2 적용

## 5. 실행 단계

각 Phase 공통 게이트: `npm run verify` + 390px 모바일 QA + HANDOFF append. 배포는 명시 요청 시에만.

- **Phase 0** (CC 직접): 디자인 토큰 파일(`lib/design-tokens.ts` 또는 CSS 변수) + 공통 컴포넌트 3종
  `HeroZone` · `PillTabs` · `WidgetCard` V2(기존 API 호환) + UI_RULES V2 초안
- **Phase 1** (Codex 구현, CC 검수): `/fleet` 파일럿 — Type A 히어로. 선박 이미지 3장(선망선·연승선·운반선) 필요
- **Phase 2** (Codex 구현, CC 검수): `/unloading`(A) `/logistics`(B) `/market`(C) + 코스모·방콕사무소 셸 V2
- **Phase 3** (opencode go — L-07 스크립트 일괄, Grok 반증 검수): commodity 전체 Type C 전환
- **Phase 4** (마무리): 전 메뉴 비밀번호 잠금(사용자 지정 비번, 기존 운영 잠금 패턴 확장) + UI_RULES V2 확정 + 룰북 개정

에이전트 배치: CC=기획·지휘·최종 편집·검수 / Codex=범위 확정 구현 / opencode go=일괄 변환 / Grok=반증·tie-break.
작성자 ≠ 검증자 규율 전 Phase 적용.
