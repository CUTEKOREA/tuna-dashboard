### 우선순위 2 — rgba 변환

rgba 리터럴은 opacity가 포함되어 있으므로 `color-mix()` 또는 CSS 변수 + opacity 별도 처리 필요:

- `rgba(255,255,255,0.1)` → `var(--glass-light)` (164 파일)
- `rgba(140,170,255,0.10)` → `var(--glass-accent)` (148 파일)
- `rgba(255,255,255,0.5)` → `var(--text-overlay)` (98 파일)

## 부록: 방법론

### 사용 도구
- **스크립트**: `/tmp/color_inventory.py` (Python 3, 표준 라이브러리만 사용)
- **스캔 대상**: `components/**/*.tsx` 429 파일
- **패턴**:
  - hex: `#(?:[0-9a-fA-F]{3}){1,2}\b`
  - rgba: `rgba?\s*\([^)]+\)`
  - hsl: `hsla?\s*\([^)]+\)`
  - var참조: `var\(--[^)]+\)`

### 분류 휴리스틱
- **경보색**: rose/red/danger/warning/amber 키워드 문맥 또는 R>180, G<80, B<80 범위
- **차트시리즈**: series/chart/line/bar/fill/stroke 키워드 또는 B>180, R<100 범위
- **장식**: bg/background/border/shadow/backdrop/gradient/glow 키워드
- **commodity시그니처**: tuna/salmon/shrimp 등 품목명 키워드
- **미분류**: 위 조건에 해당하지 않는 경우

### 검증 명령

```bash
python3 /tmp/color_inventory.py
```

> 이 명령을 실행하면 동일한 결과를 재현할 수 있다. JSON 출력은 `/tmp/color_inventory_data.json`에 저장됨.
