## 이 편에서 새로 나온 사고

| 사고 | 배운 것 |
|---|---|
| **must 목록이 앞 편 값 그대로였다** | 관문이 「다른 편 title 잔류」는 막는데 **must 목록 자체가 앞 편 것인 건 아무도 안 막았다.** 초판 빌드에서 144개 미스로 드러났다 — 골격을 복사하면 **must·산술 블록을 먼저 비워라** |
| **팩샷이 팩샷이 아니었다** | 여섯 장 전부 캔도 라벨도 없는 조리 사진이라 축 12를 형식만 통과했다. 감사가 잡았다. 브랜드 사이트에서 라벨 팩샷으로 갈아 끼우니 **캔에 인쇄된 고형량**(참치 185 g → 130 g, 고등어 155 g → 93 g)이 나왔다 — 웹 상품 페이지에 없던 값이다 |
| **두 렌즈가 같은 P0를 서로 다른 경로로 잡았다** | 렌즈 A는 설립일로(자매사는 2004년 설립), 렌즈 B는 제형으로(SPH는 pouch, 캔 B/L 화주는 자매사). **겹치지 않게 발주했는데 같은 자리를 가리킨 것은 그 결함이 진짜라는 뜻이다** |
| **법인 단위가 산문에서만 흔들렸다** | 표는 「I.S.A. Value의 거래상대」로 정확한데 산문 다섯 곳이 「그룹의」로 옮겼다. §8이 스스로 「축을 Unicord의 캔에 걸면 안 된다」고 적어 놓고 **반대 방향으로 같은 잘못**을 했다 |
| **분모 치환을 또 밟았다** | 「한국이 잡은 가다랑어의 60%가 태국으로」는 **수출 분모**였다. 어획 분모로는 40%다. 네 편 연속 나오는 함정이고 이번에도 반증에서 잡혔다 |
| **비상장이라고 숫자가 없는 게 아니다** | 계열 공개회사 하나가 재무제표를 내고, 법정 제출은 웹사이트 업로드가 멈춘 뒤에도 이어진다. **「공개하지 않는다」와 「그 주소에 없다」는 다르다** |
