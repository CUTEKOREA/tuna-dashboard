# 참치왕국 대시보드 API 고도화 제안서

- **작성일**: 2026-07-06
- **대상**: 신라교역 C레벨(의사결정) + 대시보드 개발자(구현)
- **검증 방법**: 전 제안을 3중 검증(adversarial-reviewer 반증 시도 → source-verifier 1차 출처 대조 → codex-verify 벤더 교차) 통과분만 수록. 보유 API 키로의 **라이브 실호출**(KCS nitemtrade·ECOS·US Census·KAMIS·UNI-PASS·MFDS·Comtrade), data.go.kr/공식 문서 원문 대조, 저장소 코드 grep(중복·배선 확인)을 병행했다. 반증된 클레임은 수정(EDIT) 반영해 기술했고, 미확인 사항은 미확인으로 명시했다.
- **원 제안 19건 중 유사 제안 3쌍 병합** → 최종 16개 위젯 (병합 내역은 부록 C).
- **우선순위 산식**: (신규 인사이트 가치 1~5) × (데이터 신뢰도 = 검증 confidence) ÷ (구현 비용 S=1, S~M=1.5, M=2, M+게이트=2.5). 산출 근거는 동봉 `2026-07-06_API_EXPANSION_PROPOSAL.data.json`에 구조화 수록.

## ① 요약

1. 검증을 통과한 신규 위젯 후보는 **16개** — 판매·수요 6, 물류·통관 5, 거시·금융 5. 현행 대시보드의 명시적 공백 축 4개 중 3개(국내 소매가·검색트렌드·통관 리드타임)를 메운다(해상기상 축은 이번 배치에 미포함, 공백 잔존).
2. 이 중 **9개는 보유 키 또는 무키로 즉시 착수 가능**(Part A) — KCS·ECOS·US Census는 보유 키 실호출까지 성공 확인. 나머지 7개(Part B)도 대부분 data.go.kr 자동승인 활용신청 수준이라 발급 리스크가 낮다.
3. 검증 과정에서 **현행 대시보드의 죽은 연동 3건**이 발견됐다(P0: /api/tuna의 허구 KAMIS 614 KPI, /api/risk-radar MFDS 500 오류 / P1: UNI-PASS 무역통계 404). 신규 착수 전 0단계로 정정 권고.
4. 최우선 퀵윈(S effort)은 KAMIS 대체재 바스켓·US Census 관문 레이더·DART 내부자 시그널·HS10 수입단가 매트릭스 — 전부 기배선 키 재사용이며 합산 1주 내 구현 가능 범위.
5. 전략 플래그십은 **참치캔 소매가 전가 모니터(참가격)**: 원어가→소매가 전가율·시차를 처음으로 정량화해 OEM 납품가 협상·PB 진입 판단의 수치 근거를 만든다(검증 KEEP, confidence 0.87).

### A-1. 단백질 대체재 상대가격 바스켓 (KAMIS LIVE)
- **Pillar**: 판매·수요 | **Effort**: S (반나절) | **Badge**: SYNCED
- **API·엔드포인트**: `kamis.or.kr/service/price/xml.do?action=dailyPriceByCategoryList&p_product_cls_code=01`(소매), 부류 600 수산물. KAMIS_API_KEY+CERT_ID 기배선.
- **품목코드(검증 정정)**: 고등어 **611**, 갈치 **613**, 물오징어 **619**(원안의 615는 **명태** — 그대로 구현 시 오징어 라인에 명태 가격이 무증상 편입되는 P0 오류였음. 공식 코드표 xlsx 파싱으로 확정). 명태 615를 4번째 구성품으로 추가하는 것도 저비용 옵션.
- **차트·데이터 결합**: 3~4개 품목 소매가를 100 기준 상대가격 지수로 정규화한 멀티라인 + '참치캔 대비 대체재 가격비' KPI 타일. KPI 분자는 참가격 위젯(B-1) **채택 시에만 활성** — 미채택 시 기존 `/api/atuna-prices`의 방콕 skjbkk를 임시 분모로 쓰는 fallback 정의.
- **SIT·TAK**: 고등어·오징어 어획 부진으로 대체재가 비싸지는 국면 = 참치캔 가격 인상 여력·프로모션 강도 판단 신호. 기존 Illex 오징어 위젯의 '원가(공급)' 관점을 '소비 대체' 관점으로 뒤집는 보완재.
- **주의**: '일별' 명칭은 실제 갱신 주기 확인 후 조정('22.7 이후 소매 카탈로그가 주간 비교 중심일 가능성).
- **Evidence**: KAMIS openapi 문서 + 공식 품목코드표 xlsx 파싱(로컬 사본 확보), 부류 600에 참치/다랑어 품목 없음 실측. 고등어·갈치·물오징어 최신 소매치(06/29) 실재.

### A-2. 미국 참치 수입 관문 레이더 (원산지×통관지구)
- **Pillar**: **물류·통관**(원안 판매·수요에서 이동 — district는 관문·물류 신호) | **Effort**: S | **Badge**: SYNCED(월)
- **API·엔드포인트**: `api.census.gov/data/timeseries/intltrade/imports/hs` — 보유 USCENSUS_API_KEY로 2026-04 실호출 성공(태국 $51.1M·에콰도르 $15.7M·베트남 $11.3M / district: LA $27.3M·서배너 $25.5M·NYC $23.5M).
- **차트·데이터 결합**: 통관지구(DISTRICT/DIST_NAME) 분포 도넛 + 원산지 교차를 **본체**로. 단가는 HS6 레벨 CON_QY1_MO가 구조적으로 0을 반환하므로 금지 — **HS10 와일드카드 `I_COMMODITY=160414*` 호출 후 UNIT_QY1==='KG' 행 합산**(scripts/fetch_us_census_data.js:32-42 기존 패턴 재사용), 가치·수량 GEN_ 계열 통일.
- **SIT·TAK**: 에콰도르 이탈분을 태국·베트남이 흡수하는지 + 관문(서안 vs 동안) 재편을 월 단위 포착 — 대미 OEM 파트너 선정과 물류 루트 판단.
- **중복 주의(검증 정정)**: 메인에 160414 prefetch 위젯 4개 기실재(UsTunaMarketShareWidget 등, ~2025-12 SYNCED). 본 위젯의 신규성은 **district 축 + 2026 라이브**뿐이며, 기존 4개 위젯의 2026 연장은 신규 위젯이 아니라 `fetch_us_census_data.js` TIME_RANGE 연장(→2026-05)으로 처리해 중복 신설 방지.
- **Evidence**: 실호출 4건(2026-04 데이터·district·HS10 KG·HS6 수량 0 재현), 무키 호출 302 KeyError 확인.

### A-3. DART 내부자 시그널 — 참치 상장사 지분변동 타임라인
- **Pillar**: 거시·금융 | **Effort**: S | **Badge**: SYNCED(일 배치)
- **API·엔드포인트**: `opendart.fss.or.kr/api/elestock.json` + `/api/majorstock.json` (DART_API_KEY 전 엔드포인트 공용, 일 20,000건 쿼터 대비 일 8콜).
- **차트·데이터 결합**: 종목별 주가 미니차트 위에 임원 지분변동·5% 보고 이벤트 마커 + 최근 90일 **'지분 순증'** 집계 테이블(rcept_dt 클라이언트 필터, 응답 100건 제한·빈 윈도우 Empty 상태 설계). 마커 클릭 시 rcept_no로 DART 원문 링크.
- **SIT·TAK**: 경쟁사 오너·임원의 지분 증가 클러스터는 업황 바닥 인식 신호, 5% 보고는 M&A·경영권 이벤트 조기경보. 단 **API에 취득 사유 필드가 없어** 장내매수/스톡옵션/상속 구분 불가 — 라벨을 '순매수'가 아닌 '지분 순증'으로 하고 사유 확인은 원문 링크에 위임(과대해석 방지).
- **선행 조건(P1)**: 신라교역 corp_code가 리포 내 상충(/api/dart-insight=00135962 vs /api/tuna/dart=00857727) — CORPCODE.xml 재검증 후 `app/api/_shared` 단일 출처화. 종목 구성에서 동원F&B 제외(2025-07-31 상장폐지).
- **Evidence**: 금감원 공식 문서(elestock 파라미터·필드·100건 제한), 리포 grep 두 엔드포인트 미사용 + 내부자·지분 각도 위젯 0개 확인.

- **Evidence**: 라이브 호출 4건, data.go.kr 15100475 문서(HS 2/4/6/10단위 국가별).

### A-5. 글로벌 참치캔 수출 점유율 레이스 (HS 160414, 연간)
- **Pillar**: 판매·수요 | **Effort**: S | **Badge**: SYNCED — TelemetryBadge에 **'연간 2024 확정치'** 정직 표기(L-09)
- **API·엔드포인트**: `comtradeapi.un.org/data/v1/get/C/A/HS?cmdCode=160414&flowCode=X&partnerCode=0`, reporterCode=all 또는 상위 15개국+**156(중국)+410(한국)**. UN_COMTRADE_PRIMARY_KEY 보유, 미사용 `/api/comtrade` 라우트(C/A 하드코딩과 일치) 재생.
- **재설계 사유(검증 정정)**: 월별(C/M)은 태국 최신 2025-02, 에콰도르·중국 2024-12로 17~19개월 랙 실측 — '조기 포착' 불가. **연간 레이스(2015~2024)**로 전환하면 5개국 전부 확보되고 세계 합계(분모) 문제도 해소.
- **차트·데이터 결합**: 태국·에콰도르·스페인·필리핀·중국 수출액 점유율 스트림그래프 + 한국 위치 마커. 신선 시그널은 기보유 Eurostat CSV(EU측)·US Census(미국측) 위젯이 담당함을 cardDesc에 명시.
